> 对应范围：全局框架 + 进项·AI 日报 + 进项·拆解报告（含拆解任务）+ 选题池。
> 写法：先说**验证过什么、怎么验证的**，再说**没验证的**，最后是已知差距。没有证据的不写成「已完成」。

## 一、已验证（有证据）

### 验证中发现并已修的问题

| # | 问题 | 怎么发现的 |
|---|---|---|
| 1 | 请求体模型定义在函数内，接口一律 422 | 接口测试 5 个失败 |
| 2 | 你这台机器设了 SOCKS 代理（`ALL_PROXY`），httpx 缺 `socksio`，**同步直接 500** | 真实运行才暴露，测试里用假数据看不到。已装依赖，加了回归测试，同步失败改为可读的 502 |
| 3 | 我拿来当样本的日报 RSS 被超时截断（半个汉字），测试误报解析失败 | 测试失败后查样本；已重新完整下载并校验 XML 合法 |
| 4 | 日报引擎没有 `.env` 时，「检查日报引擎」直接说未配置、不跑 doctor，信息更少 | 看真实 doctor 输出后改为照跑 |
| 5 | 引擎没装时点「拆解」，报错是裸的 `No module named` | 改成「先运行 scripts/setup.sh」，加测试 |
| 6 | 任务线程池只有一个，日报生成（10–30 分钟）会卡死所有拆解 | 自查设计时发现；改为按任务类型各一条队列，加测试 |
| 7 | 拆解失败时进度条没标出失败那一步；引擎报错是英文无指引 | 浏览器里走失败路径时发现；已标红并加排查提示 |

## 二、没有验证的（需要你的配合，我这边无法替你做）

| 内容 | 为什么没验证 | 需要什么 |
|---|---|---|
| **真实下载 → 转写 → AI 拆解一条抖音视频** | 没有抖音 cookies，也没有任何 AI（claude / codex 命令、API key 都没有）。用假的三步验证了「引擎怎么接」，没验证三步各自真实可用 | cookies + 一个 AI + `scripts/setup.sh --full` |
| **生成今日日报** | 同上，缺 AI；而且要真跑十几分钟到半小时 | 给日报引擎配 AI |
| `setup.sh --full`（装 mlx-whisper） | 体积大，走代理下载很慢，没跑 | 你确认要在本机转写时再装 |
| 窄屏 / 手机排版 | 只在 800 与 1440 宽度看过 | — |

## 四、风险与注意

- **版权**：「Park 公开库」的日报与拆解报告含原作者的原话。只在你本地看；页面和接口都标了来源。以后若要把工作台对外分享，要先清掉 `app/data/reports` 与 `app/data/newsletter` 里 `source=park_public` 的内容。
- **抖音风控**：拆解会用你的登录请求作者作品。已限制同时最多排 3 条；遇验证页引擎自己会停，不绕过。**请自己控制节奏，别批量拆。**
- **密钥**：cookies 放 `~/.douyin-teardown/`（引擎默认，且引擎拒绝放进仓库），AI key 放 `app/.env` 与 `engines/daily-newsletter/.env`，都已在 `.gitignore`。
- **本机服务**：只绑 `127.0.0.1`，没有登录；别用反向代理或端口转发暴露出去。
- **依赖固定**：两个引擎按 `scripts/engines.lock` 里的 commit 安装，升级前先重跑测试。
