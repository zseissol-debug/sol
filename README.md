# 自媒体工作台

复刻 Park（zinan92）的「帕克动手」自媒体工作台，先原样复刻，再按自己的需求改造。

## 范围

- **做**：进项、加工中、打包、发布、已发出、流量视频、Anna 助手、设置。
- **不做**：K 线日报、咨询客户、「我是谁 · 找到谁 · 卖什么」。
- 工作台本身是私有的，界面照截图复刻；背后管线用作者的开源仓库（见资料）。
